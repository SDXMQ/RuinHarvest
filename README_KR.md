# RuinHarvest (30일간의 생존)

[English (English)](./README.md)

RuinHarvest는 좀비 아포칼립스 세계관을 배경으로 한 2D 탑다운 형식의 **파밍 및 탈출(Harvest & Extraction)** 서바이벌 인디 게임입니다. 플레이어는 위험한 폐허 구역(Raid)에 진입하여 물자를 수집하고, 몰려오는 위협을 피해 탈출구로 생환하여 은신처를 강화하며 30일간 생존해야 합니다.

---

## 🎮 주요 게임 시스템

### 1. 절차적 오픈월드 & 청크 렌더링
- 시드 기반으로 자동 생성되는 무한 월드를 탐험할 수 있습니다.
- **다양한 바이옴**: 주거지, 도시, 공장단지, 병원구역, 군사기지, 산림, 호수 등 각 지역마다 다른 특징과 스폰율을 가집니다.
- 메모리 누수 방지를 위한 **자동 청크 언로드 및 델타 보존 시스템**이 구축되어 있습니다.

### 2. 하드코어 탈출 및 정산 로직
- 레이드 진입 도중 사망(KIA)하거나 시간 초과(MIA)가 되면, 하베스트 파우치(보안 컨테이너) 내의 전리품을 제외한 모든 장비와 인벤토리 획득물을 유실하게 됩니다.
- 맵 곳곳에 배치된 **탈출구**는 상호작용 방식에 따라 상이하게 설계되어 있습니다 (항시 개방, 특정 열쇠 필요, 잔여시간 제한 등).

### 3. 고지능 전술 AI (좀비 & PMC 용병)
- **A* 알고리즘** 기반의 우회 경로 탐색 및 장애물 회피 기동.
- 플레이어의 행동(달리기 소음, 총성, 은신/앉기 상태)에 실시간으로 반응하여 소음을 역추적하거나 경계 태세를 취합니다.
- **전술적 엄폐/우회**: 체력이 낮아지면 장애물 뒤로 숨어 자가 치유를 하거나, 플레이어의 측면을 기습 우회(Flank) 공격합니다.
- **세력 대립**: 플레이어뿐 아니라 PMC와 스캐브(Scav) 등 이종 AI 진영끼리도 시야 확보 시 적극적인 교전(AI vs AI)을 벌입니다.

### 4. 2.5D 그래픽스 & 조명 이펙트
- 낮, 황혼, 밤, 새벽으로 부드럽게 전환되는 **시간 시스템**과 날씨(맑음, 비, 눈, 안개 등)에 따른 스트레스/시야 변화.
- 적들이 발사하는 총기 레이저 사이트 빔(PMC와 Scav 구분) 및 화려한 총기 궤적 이펙트가 제공됩니다.

### 5. 다층 건물 탐색 (OOP 리팩토링 완료)
- 건물 내부로 진입하여 프로젝트 좀보이드 스타일의 가구 탐색(냉장고, 사물함, 무기함 등) 및 정밀 파밍이 가능합니다.
- **계단 시스템**: 건물 내부 계단을 통해 다층(2층 등) 구조의 내부 맵을 매끄럽게 오르내릴 수 있습니다.
- **창문 시야**: 건물 안에서 창문 곁에 서서 마우스 방향을 주시하면, 창밖 실외의 좀비 동태와 물자를 실시간으로 감시할 수 있습니다.

### 6. 가상 플리마켓 & 은신처(Hideout) 정비
- 레이드에서 가져온 아이템을 가상 플리마켓(Flea Market)에 등록하여 시세 변화에 맞춰 판매하고 루블을 벌 수 있습니다.
- 은신처 전용 상인들과 물물교환을 하거나, 획득한 전리품으로 창고(Stash) 크기를 업그레이드하고 회복할 수 있습니다.

## 🛠 최근 업데이트 및 변경 사항

- **PMC 스폰 밸런싱**: PMC(`tank`, `spider`)의 출현 확률을 기존 `2%`에서 `0.2%`로 대폭 하향하여, 고가치 군사구역이나 병원 등에서만 극히 드물게 마주치는 타르코프식 밸런스를 구축했습니다.
- **히트박스 정밀화**: 단일 픽셀 검사 방식에서 캐릭터 발바닥 영역을 감싸는 4점식 사각형 바운딩 박스로 충돌 검사를 개편하여 벽 모서리를 비정상적으로 파고드는 버그를 해결했습니다.
- **지붕 위 통행 방지 및 반투명 렌더링**: 야외에서 건물 지붕으로 올라가 통과하는 비현실적인 설계를 차단(이동 제한)했습니다. 대신 건물 북쪽 뒤편으로 이동하여 가려질 때 건물이 자동으로 반투명(alpha 128)으로 전환되어 시야가 확보되도록 렌더링 방식을 개선했습니다.
- **떠돌이 상인 플레이어 감지 AI**: 상인이 `IDLE` 상태일 때도 플레이어가 근처에 감지되면 느낌표(`!`)를 띄우고 서서히 다가오도록 행동 인공지능을 수정했습니다.
- **광원 도구 내구도 소모**: 밤 시간대나 어두운 건물 내부에서 `손전등`, `횃불`, `개조 손전등` 소지 시 내구도(배터리)가 실시간으로 소모되며, 방전 시 자동으로 파괴 및 소멸되도록 현실성을 높였습니다.
- **고가치 전리품 추가**: 게임에 고부가가치 아이템인 `"암호화된 SSD"`와 `"군용 나침반"`을 추가하고, 전용 픽셀 아이콘을 디자인하여 각 파밍 테이블(군사기지, 공장, 경찰서)에 배치했습니다.

## ⌨️ 기본 조작 방법

| 조작키 | 행동 설명 |
| :---: | :--- |
| **W, A, S, D / 방향키** | 이동 |
| **LSHIFT (쉬프트)** | 달리기 (스태미나 급격히 소모, 소음 대폭 증가) |
| **LCTRL (컨트롤)** | 은신/앉기 (속도 반감, 좀비 탐지 거리 감소, 발소리 없음) |
| **E** | 상호작용 (아이템 줍기, 대화, 문/계단 진입, 파밍 등) |
| **마우스 왼쪽 클릭** | 장착한 무기로 공격 / 사격 (총기 장착 시 탄약 필요) |
| **B** | 인벤토리 창 열기 / 닫기 |
| **C** | 제작(크래프팅) 창 열기 / 닫기 |
| **M** | 전술 지도 창 열기 / 닫기 (안개 지도) |
| **F5** | 빠른 저장 (Autosave) |
| **ESC** | 게임 일시정지 (메뉴 표시) |

## ⚙️ 실행 및 빌드

본 게임은 **Python 3** 및 **pygame-ce**를 사용하여 실행됩니다.

1. 의존성 패키지 설치:
   ```bash
   pip install -r requirements.txt
   ```
2. 게임 실행:
   ```bash
   python src/main.py
   ```
3. 시스템 무결성 검증:
   ```bash
   python src/validate.py
   ```
