## 개요

**RuinHarvest**는 **Godot 4.7** 엔진으로 제작된 싱글플레이 2D 탑다운 전술 익스트랙션 슈터 게임입니다. 은신처(Hideout)에서 장비를 정비한 뒤 절차적으로 생성되는 폐허 구역에 투입되어, 진입 가능한 다층 구조의 건물들을 수색하고 적대 세력과 감염체를 상대하며 현장 목표를 완수하고 제한 시간 내에 탈출 지점까지 생환하는 것이 목표입니다.

레이드에서 무사히 탈출하면 배낭 속 전리품을 모두 은신처로 가져올 수 있습니다. 반면 작전 중 사망(**KIA**)하거나 제한 시간을 초과(**MIA**)하면 일반 배낭의 아이템을 잃게 되며, 좌상단 **2×2 안전 파우치(Secure Pouch)** 안에 보관한 물품과 **보험에 가입한 장비**만 보존됩니다.

## 주요 특징

### 은신처, 경제 및 성장 시스템
- **2D 그리드 인벤토리 & 안전 파우치 (`InventoryGrid`):** 타르코프 스타일의 `W×H` 칸 점유 그리드를 지원하며 아이템 회전(`R`), 수량 분할, 자동 정렬, 빠른 이동/장착(`Ctrl+클릭` / `우클릭`)이 가능합니다. 배낭 좌상단 **2×2 안전 파우치**에 넣은 열쇠, 키카드, 탄약 등 귀중품(무기·방어구·리시버 제외)은 사망 시에도 보호됩니다.
- **장비 슬롯 & 장비 보험:** 헬멧, 방탄복, 배낭(장착 배낭에 따라 레이드 가방 크기 가변), 하의/신발, 주무기 1, 주무기 2, 보조 무기, 투척 무기 슬롯을 지원하며, 출격 전 `1,500 RUB`로 장착 장비 보험에 가입할 수 있습니다.
- **3인 상인 (`ItemDatabase`):**
  - **프라포 (Prapor):** 총기, 리시버, 탄약, 방어구, 부착물
  - **테라피스트 (Therapist):** 의료품, 식량, 식수
  - **펜스 (Fence):** 제작 재료, 도구, 장거리 무전기, 무기고 열쇠, 보안 키카드
- **가상 플리마켓 (`FleaMarket`):** 일차별 시세 변동, 플레이어 매물 등록(수수료 5%), 그리고 암시장 **오늘의 2.5배 긴급 수배 납품** 시스템을 제공합니다.
- **은신처 시설 업그레이드 & 상인 의뢰 (`HideoutProgression`):**
  - **4종 시설 (최대 Lv.3):** 보관함 확장(최대 `10×24`), 응급 의료 스테이션(최대 체력 증가), 발전기 & 채굴 서버렉(생존 복귀마다 패시브 루블 수익), 통신 & 거래소 인텔 센터(상인 구매 할인 및 판매 단가 상승).
  - **7종 상인 의뢰 & 복무 기록:** 물자 납품, 적 처치, 현장 단말기 해킹 임무 및 무기별 3단계 숙련도 기록을 지원합니다.

### 모듈식 총기 커스터마이징 & 사격장
- **7종 총기 리시버 (`WeaponPartsDatabase`):** `M9`, `MP5A5`, `AK-47`, `M4A1`, `레밍턴 870`, `윈체스터 레버액션`, `SV-98`.
- **7종 부착물 슬롯:** 총열(Barrel), 총구(Muzzle), 개머리판(Stock), 손잡이(Grip), 탄창(Magazine), 조준경(Optic), 전술 레일(Rail).
- **6종 탄약:** `9mm`, `.45 ACP`, `5.56x45mm`, `7.62x39mm`, `12게이지 벅샷`(8펠릿), `12게이지 슬러그` (레이드 중 `Alt + R`로 호환 탄종 전환 가능).
- **스마트 프리셋 & 지하 사격장 (`F2`):** 부족한 부품을 자동 구매·조립해 주는 원클릭 프리셋 기능과, `10m / 25m / 50m` 과녁, 정조준(ADS) 줌, 반동·집탄율 확인 및 무한 탄약 토글을 지원하는 사격장을 제공합니다.

### 절차적 월드, 전투 및 생존
- **청크 기반 절차적 월드 (`WorldGenerator`):** `16×16` 타일(`32px`) 단위의 청크 스트리밍으로 도심 직교 도로망과 외곽 곡선 도로가 결합된 맵을 생성하며, `주거지`, `상업`, `공업`, `군사`, `산림` 바이옴과 **12종의 건물 프리셋**이 배치됩니다.
- **상호작용 환경 & 건물 내부:** 직접 진입 가능한 건물 내부 씬(`building_interior_scene.gd`), 여닫을 수 있는 문, 파손 시 소음이 발생하는 창문, 열쇠/키카드가 필요한 보안 금고 및 무기고, 가동 시 실내 조명과 전자식 잠금문·지하 벙커 탈출구를 개방하는 전력 스위치가 구현되어 있습니다.
- **적대 개체 (`enemy.gd`):** `좀비`, `러너`, `탱크`, `스캐브`(원거리 무장), `레이더`(정예 무장), `보스`(점사 및 수류탄 투척), `야간 추격자(Night Stalker)`(어둠 속에서 반투명 은신, 손전등 비출 시 노출)가 등장합니다.
- **전술 생존 시스템 (`SurvivalStats`):** 체력, 스태미나, 배고픔, 갈증, 무게 단계(`35kg` 과적 주의, `50kg` 초과 시 질주 불가 및 이속 감소), 방어구 내구도 마모, 총기 기능 고장(잼)/공격발, 상태이상(**출혈**, **골절**, **감염**) 및 채널링 기반 소비 아이템 사용을 지원합니다.
- **조명, 날씨 및 시각 효과:** 낮/밤 시간 변화, 실시간 그림자를 드리우는 손전등(`F`), 야간투시경(`N`), 6종 날씨(`맑음`, `흐림`, `비`, `폭우`, `안개`, 뇌우를 동반한 `폭풍`) 및 후처리 셰이더(비네트, 블룸, 색수차)가 적용됩니다.
- **전술 도구 & 탈출 (`main_world.gd`):**
  - 상단 나침반 바, 전술 지도(`M`), 현장 제작(`C`), 현장 총기 개조(`B`).
  - **전술 무전기 (`U`, 가방에 무전기 보유 시):** 주변 적·보급·보스 주파수 스캔, 긴급 탄약·의료 드론 투하 호출, **풀턴(Fulton) 회수 풍선**을 통한 아이템 1종 중도 은신처 이송.
  - **3종 현장 임무 & 항공 보급:** 군사 단말기·생체 표본 채취기·무선 중계기에서 `E` 키를 `3.0초`간 홀드하면 디펜스 웨이브가 발생하며, 완료 시 추가 보너스와 벙커 탈출구가 개방됩니다.
  - **3종 탈출 지점:** 일반 탈출구(`7초`), 유료 장갑차 탈출(`3,000 RUB` / `2초`), 비상 벙커 탈출구(`5초`, 현장 단말기 해킹 또는 전력 복구 필요).

### 게임 모드 & 다국어 지원
- **새 레이드 프리셋 & 커스텀 규칙:** `캐주얼`, `스탠다드`, `하드코어`, `커스텀` 프리셋과 좀비 밀도(`50%`~`250%`), 레이드 제한 시간(`10 / 20 / 30 / 60분` 또는 `무제한`), 루팅 배율, 낮/밤 주기, 시작 자금, **하드코어 영구 사망(Permadeath)** 옵션을 설정할 수 있습니다.
- **샌드박스 모드:** 좀비 밀도 및 루팅 배율 최대 `400%`, 시작 자금 최대 `100,000 RUB` 설정, ESC 메뉴를 통한 즉시 안전 복귀, 치트/아이템 스포너(`F1`)를 지원합니다.
- **다국어 지원 (`I18nManager`):** `resources/i18n/translations.csv`를 통해 한국어(`ko`)와 영어(`en`)를 지원합니다 *(일부 인게임 UI 및 아이템 명칭은 한국어 중심으로 작성되어 있습니다)*.

## 시작하기

### Windows 한 줄 설치 (PowerShell)

PowerShell 한 줄로 **RuinHarvest**를 `C:\Program Files\RuinHarvest`에 일반 Windows 응용프로그램처럼 설치합니다(필요 시 UAC 관리자 권한을 자동으로 요청하며, 시작 메뉴·바탕화면 바로가기 생성 및 Windows **설치된 앱**에 제거 항목을 등록합니다).

```powershell
irm https://raw.githubusercontent.com/SDXMQ/RuinHarvest/main/install.ps1 | iex
```

> [!IMPORTANT]
> [install.ps1](install.ps1)은 최신 [GitHub Release](https://github.com/SDXMQ/RuinHarvest/releases)에 업로드된 `RuinHarvest.exe`(또는 Windows `.zip` 빌드)를 내려받아 설치합니다(정식 릴리스가 없으면 최신 Pre-release를 사용합니다). 이 명령을 사용하려면 먼저 GitHub Releases에 Windows 실행 파일이 등록되어 있어야 합니다.

제거할 때는 **Windows 설정 → 앱 → 설치된 앱 → RuinHarvest**에서 제거하거나 아래 명령을 실행하세요(세이브 파일은 `%APPDATA%\Godot\app_userdata\RuinHarvest`에 보존됩니다).

```powershell
& "$env:ProgramFiles\RuinHarvest\uninstall.ps1"
```

### 소스 코드에서 직접 실행 (Godot 4.7)

#### 요구 사항
- **Godot Engine 4.7** (Forward Plus 렌더러, `project.godot` 기준)
- *(선택 사항 — 픽셀 스프라이트 시트 재생성 시에만 필요)* **Python 3**, `numpy`, `Pillow`

#### 실행 방법
1. 저장소를 클론합니다.
   ```bash
   git clone https://github.com/SDXMQ/RuinHarvest.git
   ```
2. **Godot Engine 4.7**을 실행하고 `project.godot` 파일을 가져옵니다(Import).
3. **F5** 키(또는 **프로젝트 실행**)를 눌러 `res://scenes/main_menu/main_menu.tscn`에서 게임을 시작합니다.

#### 픽셀 아트 아틀라스 재생성 (선택 사항)
디퓨즈(`*_d.png`) 및 OpenGL 노말 맵(`*_n.png`) 아틀라스는 이미 `assets/pixel/` 경로에 포함되어 있습니다. `scripts/tools/bake_pixel_assets.py`를 수정한 경우 아래 명령으로 다시 생성할 수 있습니다.
```bash
pip install numpy pillow
python scripts/tools/bake_pixel_assets.py
```

## 프로젝트 구조

```text
RuinHarvest/
├── assets/pixel/              # 베이크된 픽셀 스프라이트 시트 (*_d.png, *_n.png), 아이콘 및 manifest.json
├── autoload/                  # 전역 싱글톤 (GameManager, SaveManager, ItemDatabase, I18nManager 등)
├── data/items/                # 아이템 리소스 정의 (.tres)
├── graphics/shaders/          # 커스텀 셰이더 (pixel_entity, hit_flash, post_process, water_foliage)
├── resources/i18n/            # 다국어 번역 테이블 (translations.csv)
├── scenes/
│   ├── entities/              # 플레이어(카메라, 조명, 스탯, 무기), 적, 탄환, 바닥 아이템
│   ├── hideout/               # 은신처 UI, 창고/배낭 그리드, 상인, 플리마켓, 작업대
│   ├── interior/              # 건물 내부 진입 씬
│   ├── main_menu/             # 메인 메뉴, 새 레이드 설정, 샌드박스 메뉴
│   ├── ui/                    # 인벤토리, 크래프팅, 지도, 무전기, 총기 개조, 사격장, 설정
│   └── world/                 # 메인 레이드 월드, 청크 매니저, 월드 생성기, 탈출구, 오브젝트
├── scripts/tools/             # 에셋 파이프라인 스크립트 (bake_pixel_assets.py)
├── systems/                   # 핵심 시스템 (2D 인벤토리 그리드, 무기 부품 DB, 성장, 날씨, 이벤트 등)
├── ui/theme/                  # 전술 픽셀 UI 테마 (tactical_theme.tres)
├── world/interior/            # 건물 내부 레이아웃 생성기
└── install.ps1                # Windows 한 줄 PowerShell 설치 스크립트 (Program Files + 바로가기 + 앱 등록)
```
